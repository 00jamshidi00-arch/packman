# پک‌من (Pac-Man) — پروژه جاوا

پیاده‌سازی ساده‌ی بازی کلاسیک پک‌من با استفاده از **Java Swing/AWT**.

## ویژگی‌های پروژه

- رابط گرافیکی با Java Swing (پنجره‌ی بازی + پنل امتیازات)
- حرکت پک‌من با کلیدهای جهت‌دار (Arrow Keys)
- هوش مصنوعی ساده برای روح‌ها (Ghosts)
- سیستم امتیازدهی و ذخیره‌ی رکوردهای برتر (High Scores) در فایل متنی
- نمایش تعداد جان‌ها، امتیاز و وضعیت پایان بازی (باخت/برد)

## ساختار پروژه

```
packman/
├── Main.java                  نقطه شروع برنامه
├── model/
│   ├── GameMap.java           منطق و داده‌های نقشه بازی
│   └── Ghost.java             منطق حرکت و رفتار روح‌ها
├── score/
│   └── ScoreManager.java      خواندن/نوشتن و مدیریت رکوردهای برتر
└── ui/
    ├── MainFrame.java         پنجره اصلی برنامه (JFrame)
    ├── GamePanel.java         پنل اصلی بازی و حلقه رندر/آپدیت
    └── ScorePanel.java        پنل نمایش رکوردها و شروع بازی جدید
```

## مشخصات محیط اجرا (Requirements)

| مورد | مقدار |
|---|---|
| زبان | Java (JDK) |
| نسخه پیشنهادی JDK | 17 نسخه LTS|
| کتابخانه‌های خارجی | ندارد — فقط از کتابخانه‌های استاندارد جاوا (`javax.swing`, `java.awt`, `java.io`, `java.util`) استفاده شده |
| IDE پیشنهادی | IntelliJ IDEA (پروژه با ویسکود نوشته شده) |
| سیستم‌عامل | هرجایی که JDK و محیط گرافیکی (Desktop/GUI) ویندوز، لینوکس، مک |

## نحوه نصب و راه‌اندازی (Setup)

### روش ۱: اجرا از طریق خط فرمان (بدون IDE)

1. پروژه را کلون یا دانلود کنید و وارد پوشه‌ی اصلی آن شوید (پوشه‌ای که فولدر `pacman` داخلش قرار دارد، یعنی یک سطح بالاتر از پکیج `pacman`).

2. کامپایل کل سورس‌ها:
```bash
javac -d out $(find . -name "*.java")
```
یا در ویندوز (PowerShell):
```powershell
javac -d out (Get-ChildItem -Recurse -Filter *.java).FullName
```

3. اجرای برنامه:
```bash
java -cp out pacman.Main
```

### روش ۲: اجرا از طریق IntelliJ IDEA / Eclipse

۱. یک پروژه‌ی جدید از نوع Java باز کنید (Open یا Import Project) و مسیر پوشه‌ای که فولدر `pacman` (پکیج ریشه) در آن قرار دارد را به‌عنوان **Source Root** انتخاب کنید.
۲. مطمئن شوید Project SDK روی یک نسخه‌ی JDK نصب‌شده (ترجیحاً 17+) تنظیم شده است.
۳. فایل `Main.java` را باز کرده و Run بگیرید (متد `main` نقطه‌ی شروع است).

## نحوه بازی

| کلید | عملکرد |
|---|---|
| ↑ | حرکت به بالا |
| ↓ | حرکت به پایین |
| ← | حرکت به چپ |
| → | حرکت به راست |

هدف بازی جمع‌آوری نقاط داخل نقشه و فرار از روح‌هاست. با هر بار از دست دادن جان، یکی از سه جان بازیکن کم می‌شود و در پایان بازی (برد یا باخت)، امتیاز نهایی در فایل رکوردها ذخیره می‌شود.

## فایل رکوردها (High Scores)

رکوردهای برتر به‌صورت خودکار در فایلی به نام `pacman_highscores.txt` در همان مسیری که برنامه اجرا می‌شود ذخیره می‌شوند (حداکثر ۱۰ رکورد برتر نگه داشته می‌شود). نیازی به ساخت دستی این فایل نیست؛ در صورت نبودن، به‌طور خودکار ساخته می‌شود.
